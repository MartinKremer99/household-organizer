# Household Organizer

Private household inventory and shopping app.

## Requirements

- Node.js 20.9 or later
- [pnpm](https://pnpm.io/) 11

## Getting started

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
pnpm typecheck
pnpm lint
pnpm build
```
